# Données météo

`weather_2024_luz_saint_sauveur.csv` contient une série horaire 2024 pour la
zone de Luz-Saint-Sauveur, aux coordonnées 42.86 N, 0.00 E.

Source de génération : Open-Meteo Historical Weather API, variable
`temperature_2m`, fuseau `Europe/Paris`, modèle historique fourni par
Open-Meteo. La série est une donnée de réanalyse et non une extraction brute
d'une station Météo-France.

La station locale de Luz-Saint-Sauveur publiée par Infoclimat est utilisée
comme référence géographique et de comparaison climatologique.
